# أذان (Adhan) - تطبيق مواقيت الصلاة والقبلة مفتوح المصدر

تطبيق إسلامي حديث، سريع، خفيف، ومفتوح المصدر بنسبة 100%، مصمم خصيصاً لمنصة Android ومتوافق تماماً مع متطلبات متجر **F-Droid**.

---

## 🌟 المميزات الرئيسية

### 1. ⏱️ مواقيت صلاة دقيقة بدون إنترنت (Offline-First)
- محرك حساب فلكي دقيق وموثوق وفق المعايير والجمعيات الإسلامية الكبرى دون أي اعتماد على خوادم خارجية.
- طرق الحساب المدعومة:
  - **أم القرى - مكة المكرمة** (افتراضي)
  - **رابطة العالم الإسلامي (MWL)**
  - **الهيئة المصرية العامة للمساحة**
  - **جامعة العلوم الإسلامية بكراتشي**
  - **الجمعية الإسلامية لأمريكا الشمالية (ISNA)**
  - **دبي / دولة الإمارات العربية المتحدة**
  - **وزارة الأوقاف والشؤون الإسلامية - الكويت**
  - **وزارة الأوقاف والشؤون الإسلامية - قطر**
  - **معهد الجيوفيزياء - جامعة طهران**
- المذهب الفقهي لحساب صلاة العصر:
  - **جمهور الفقهاء (الشافعي، المالكي، الحنبلي)** - ظل المثل الواحد.
  - **المذهب الحنفي** - ظل المثلين.
- إمكانية تعديل دقائق المواقيت يدوياً (+/- 60 دقيقة لكل صلاة).
- إمكانية التبديل الاختياري لجلب المواقيت عبر **Aladhan API** مع رجوع تلقائي للمحرك المحلي عند انقطاع الاتصال.

### 2. 🧭 اتجاه القبلة التفاعلي (Qibla Compass)
- حساب الزاوية العظمى المباشرة (Great Circle) إلى الكعبة المشرفة بمكة المكرمة بدقة رياضية.
- استخدام مستشعرات الحركة والبوصلة المغناطيسية للجهاز مع مرشح تنعيم (Low-Pass Filter) لمنع الاهتزاز.
- مؤشر تفاعلي ملون ومؤشر اهتزاز بصري عند التوجه نحو القبلة مباشرة.
- عرض المسافة الدقيقة بين موقع المستخدم ومكة المكرمة بالكيلومترات.
- وضع توافقي في حال عدم توفر مستشعر مغناطيسي في الهاتف.

### 3. 🔔 تنبيهات وأذان محلي موثوق (Exact Alarms & Background Service)
- جدولة تنبيهات الأذان محلياً باستخدام `AlarmManager.setExactAndAllowWhileIdle()` للعمل تحت وضع السكون **Android Doze**.
- تشغيل صوت الأذان كاملاً عبر خدمة خلفية (`Foreground Service`) مع إمكانية إيقافه مباشرة من الإشعار.
- تنبيهات مسبقة قبل وقت الصلاة (5، 10، 15 دقيقة) للاستعداد للوضوء والمسجد.
- تخصيص كامل للإشعارات لكل صلاة بشكل منفصل (أذان كامل / تنبيه عادي / صامت).
- إمكانية اختيار ملف أذان مخصص من ذاكرة الجهاز.

### 4. 🔒 الخصوصية والأمان (F-Droid Ready)
- **بدون أي إعلانات** نهائياً.
- **بدون أي تتبع أو تحليلات** (خالٍ تماماً من Google Analytics و Firebase Analytics).
- **بدون حساب أو تسجيل دخول**.
- يعمل بالكامل دون الحاجة إلى اتصال بالإنترنت أو خدمات Google Play Services.
- استخدام محلي تام لبيانات الموقع الجغرافي (GPS أو اختيار يدوي من قائمة تضم أكثر من 40 عاصمة ومدينة إسلامية).

## 🛠️ التقنيات المستخدمة

- **لغة البرمجة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose & Material 3 بتصميم إسلامي مخصص (زمردي وذهبي) ودعم كامل للغة العربية (RTL).
- **قاعدة البيانات والتخزين المحلي:** Room Database + Encrypted/Local SharedPreferences
- **معمارية المشروع:** MVVM (Model-View-ViewModel) + Clean Architecture
- **إدارة المزامنة والشبكة الاختيارية:** Retrofit + Moshi (Aladhan REST API)

المشروع مصمم ليُبنى من الكود المصدري باستخدام Gradle، ولا يعتمد على Google Play Services أو Firebase أو مفاتيح API سرية. لا يحتوي على إعلانات أو تحليلات أو تتبع للمستخدم.

يمكن لمشروع F-Droid بناء التطبيق من مستودع Git العام بعد إضافة بيانات الإصدار وبيانات التطبيق المطلوبة.

## F-Droid packaging

This repository contains the complete source code and Fastlane-compatible store metadata used for F-Droid packaging. The app can calculate prayer times locally and optionally query the public Aladhan API when the user enables online calculation.
